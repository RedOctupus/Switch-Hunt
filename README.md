# 开关猎杀 (Switch Hunt) — 可玩版

Pygame 迷宫捉迷藏：玩家躲藏、开灯定身，鬼由已训练 DQN 推理追击。

> 本分支 `game-only` 仅保留游玩所需代码，已移除训练系统。完整训练管线见 `main` 分支（`train.py` / `dqn_training_system_v8.py`）。

## 结构

```
switch_hunt/
  config/     # 光源、鬼速度、出生距离
  core/       # 地图、寻路、实体、视野
  game/       # 音效、UI、主循环
  rl/         # DQN 网络 + 推理加载（不含训练）
apps/play.py  # 启动入口
models/       # ghost_v8.pth（若仓库未含模型，需自行放入）
```

## 安装与运行

推荐使用 conda 环境：

```bash
conda activate switch-hunt   # 或自行创建并 pip install -r requirements.txt
python apps/play.py
# 或
python switch_hunt_v8_game.py
```

将 `models/ghost_v8.pth` 放在项目 `models/` 目录下；缺失时鬼会退化为随机移动。启动时若看到 `Ghost model loaded`，说明 DQN 已生效。

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 强化光源（半径 5 格，照射下鬼渐变蓝至定身） |

## DQN 鬼 AI 简介

本游戏的鬼不是写死规则追人，而是用 **Deep Q-Network（DQN）** 在迷宫里学「往哪走」。

- **输入**：当前局面编码成 `7 × 21 × 21` 的网格特征图  
- **输出**：4 个离散动作的 Q 值（上 / 下 / 左 / 右）  
- **决策**：每完成一格移动后，选 Q 值最高的方向迈向下一个格子（网格对齐移动）  
- **网络**：三层卷积 + BN，再经全连接输出 4 维动作（见 `switch_hunt/rl/network.py`）  
- **权重**：游玩时加载 `models/ghost_v8.pth` 做推理；本分支不含训练循环

### 状态通道（7 通道）

| 通道 | 含义 | 作用 |
|------|------|------|
| 0 | 墙壁地图 | 感知迷宫结构 |
| 1 | 鬼位置（one-hot） | 自身定位 |
| 2 | 玩家位置（one-hot） | 追击目标 |
| 3 | A\* 最短路径 | 方向引导，降低盲目探索 |
| 4 | 危险区 | 强化光源激活时的定身威胁范围 |
| 5 | 光源冷却 | 玩家开灯后的空窗期 |
| 6 | 光源次数比例 | 剩余 charges / max，区分「可引诱」与「可冲刺」阶段 |

### 训练时在学什么（重点）

训练目标不是单纯「离玩家近」，而是学会一套 **冲刺 / 引诱 / 躲避光源** 的博弈：

1. **方向学习**  
   奖励看「这一步是否朝 A\* 正确方向走」，而不是只看绝对距离，促使鬼学会沿最优路径逼近。

2. **三阶段课程学习**（默认约 500 回合）  

   | 阶段 | 回合（约） | 场景 | 学习重点 |
   |------|------------|------|----------|
   | Phase 1 | 1–100 | 玩家静止、无光源 | 纯追击与正确方向 |
   | Phase 2 | 101–250 | 玩家静止、有 3 次开灯 | 引诱：靠近触发开灯，自己不被定身 |
   | Phase 3 | 251–500 | 玩家 AI 移动 + 有光源 | 完整动态博弈 |

3. **关键奖励信号**（训练侧配置，`main` 分支 `config_v8.py`）  

   | 信号 | 典型量级 | 含义 |
   |------|----------|------|
   | 抓到玩家 | +30 | 最终成功 |
   | 引诱成功 | +15 | 诱使玩家开灯且自己没被定身 |
   | 高风险区 / 引诱区靠近 | 小额正奖 | 鼓励压迫、逼灯 |
   | 被定身 | −8 | 惩罚硬闯强化光源 |

4. **与玩法规则对齐的约束**  
   - 鬼按格移动，动作与位移一一对应（离散 step，避免「空动作刷奖励」）  
   - 强化光源内需持续曝光一段时间才定身；鬼要学会读危险区与冷却窗口  
   - 光源次数写入状态，便于在「还有灯」时引诱、在「灯用尽」时全力冲刺  

> 可玩版当前强化光源半径为 **5 格**（见 `switch_hunt/config/default.py`）；训练时危险区通道与当时配置一致。若你改了半径/曝光时间，旧权重仍可加载，但行为可能与训练分布略有偏差。

### 想重新训练？

请切换到 `main` 分支，使用其中的训练入口，例如：

```bash
git checkout main
python train.py            # 默认 500 回合
python train.py -e 1000    # 更多回合
python train.py -r 1       # 带画面训练
```

训练产物放到本分支的 `models/ghost_v8.pth` 即可在可玩版中使用。
